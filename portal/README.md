# Royal Club Portal Preview

This is the first responsive portal UI for Royal Club.

## Included in this milestone
- Luxury emerald, gold and ivory visual system
- Responsive home dashboard for phones, tablets and laptops
- Separate Rummy and Solo Progressive Spades entry pages
- Rummy and Spades lobby interface concepts
- Profile and friends page placeholders
- Preview-only sign-in interaction

## Not connected yet
- Secure registration, login, password reset or sessions
- Nakama authentication, matchmaking, room creation or invitations
- Persistent profiles, friends, statistics or game history
- Rummy or Spades gameplay engines

The homepage is served from `/portal/` through the root Netlify `_redirects` rewrite. The original root `index.html` and existing Rummy prototype are preserved unchanged on this branch.
